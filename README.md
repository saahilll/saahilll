**[Prism](https://github.com/saahilll/Prism)** · *LLM gateway*
An OpenAI-compatible gateway that puts one endpoint in front of multiple model providers and solves the problems every AI feature hits in production:
- **Cost control:** per-team budgets and rate limits enforced atomically, with usage-based cost metering
- **Reliability:** timeout, retry, and automatic failover across providers
- **Efficiency:** difficulty-based routing to cheaper models (20/20 on its eval vs. 0.45 baseline) and a semantic cache that serves repeat questions at zero cost
- React ops console, 67 automated tests, one-command Docker deployment

`Python` `PostgreSQL` `pgvector` `Redis` `React` `Docker`

**[Prolifo](https://github.com/saahilll/prolifo)** · *Explainable AI matching*
A hybrid RAG engine that ranks candidates against job descriptions and explains every result.
- Combines semantic search (ChromaDB) and keyword search (BM25) using Reciprocal Rank Fusion
- Enforces must-have requirements before scoring
- Scores each match 0–100 with a plain-language reason, because AI rankings people can't question don't get adopted

`Python` `ChromaDB` `OpenAI embeddings` `BM25`
